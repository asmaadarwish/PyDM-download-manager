# PyDM — handoff notes (v3.4.0)
Goal: IDM-style Windows download manager (Python), installer built with NSIS (pydm.nsi in build dir), Chrome MV3 extension in extension/. (No Edge support/mentions: the user does not use Edge.)
Architecture: service process (engine.py + server.py + tray in app.py) + separate UI process (gui.py, plain tkinter/ttk, talks via remote.py HTTP). shell.py = light helpers shared by UI.
UI (v3.4.0): classic IDM look, light only. Menu bar, icon toolbar (icons/tb_*.png, generated by mkicons.py from the old line icons), categories tree (All Downloads + categories, Unfinished, Finished, Queues), ONE ttk.Treeview for the list (only changed cells are updated), IDM-style Add URL / Download File Info / Options / Scheduler / Delete dialogs. No customtkinter any more. Web UI in ui/ is only the fallback when tkinter is missing.
Bundled at build (lib/, bin/, runtime/ are not in the source zip): CPython 3.12 win-64 + tcl/tk (conda-forge), yt-dlp (+ejs, certifi, brotli, mutagen, pycryptodomex, websockets, requests), Pillow, pystray, ffmpeg.exe (imageio-ffmpeg wheel), deno.exe (npm @deno/win32-x64).
Install layout: $LOCALAPPDATA\Programs\PyDM\{runtime\, app\, pydm.ico}; app\ = these files + lib\ + bin\. shell.py points TCL_LIBRARY/TK_LIBRARY at runtime\tcl.
