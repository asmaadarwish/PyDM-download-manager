# PyDM

An IDM-style download manager for Windows: multi-connection downloads with pause/resume, queue and scheduler,
a browser extension that catches files and videos, and video download from web pages (yt-dlp).

Created by Asmaa Darwish - Content Me (http://asmaadarwish.com/)

## Install
Download **PyDM-Setup.exe** from [Releases](https://github.com/asmaadarwish/PyDM-download-manager/releases/latest) and run it.
Windows SmartScreen may warn because the installer is not code-signed: choose *More info → Run anyway*.

## Updates and privacy
PyDM reads `status.json` from this repository (a plain HTTPS request, nothing about you is sent) to
tell you when a new version exists. It collects no usage data.
